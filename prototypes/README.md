# Prototypes (bản nháp vứt đi)

Hai bản thử nghiệm đồ họa 2D cho hướng "tòa nhà mặt cắt", làm để chọn phong cách trước khi viết kế hoạch chi tiết.
Không có test, không thuộc app, không nằm trong build.

- `spike-pixel/`: pixel art dựng bằng code.
- `spike-toon/`: hoạt hình 2D vector, chơi chỉ bằng chuột/chạm (hướng đang cân nhắc).

Chạy thử (từ thư mục gốc repo):

```bash
npx vite prototypes/spike-toon --port 5182
npx vite prototypes/spike-pixel --port 5181
```
